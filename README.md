# kbamponsem.github.io

Personal site for Kwabena Boateng Amponsem. Static, text-only, no framework — built by
GitHub Pages with Jekyll so posts are plain Markdown files.

Live at **https://kbamponsem.github.io/**

## Pages

| URL | Source |
| --- | --- |
| `/` | `index.html` |
| `/cv/` | `cv.html` |
| `/writing/` | `writing/index.html` |
| `/writing/<slug>/` | files in `_posts/` |
| `/feed.xml` | generated by `jekyll-feed` |

## Writing a post

1. Create `_posts/YYYY-MM-DD-some-slug.md`.
2. Start it with front matter:

```markdown
---
title: Removing the server from a two-person app
description: One sentence for search results and the feed.
---

Body text in Markdown.
```

3. Commit and push. The URL becomes `/writing/some-slug/`.

`_drafts/` holds unpublished posts — rename from `_drafts/foo.md` to
`_posts/YYYY-MM-DD-foo.md` to publish.

## Structure

```
_config.yml          site config, plugins (feed, sitemap)
_layouts/default.html  page shell: head, header, footer
_layouts/post.html     post shell
index.html           home: intro, recent writing, work, experience
cv.html              full CV
writing/index.html   index of all posts
_posts/              published posts
_drafts/             unpublished posts
styles.css           the whole stylesheet
assets/              images
```

## Editing the CV

`cv.html` is the full CV, hand-written HTML. Keep it in sync with LinkedIn — where they
disagree, LinkedIn is the current record.

## Local preview

Jekyll is not installed on this machine; GitHub Pages builds the site. To preview locally:

```sh
gem install --user-install jekyll jekyll-feed jekyll-sitemap
jekyll serve --livereload
```

Or push and wait ~30s for the Pages build.

Printing `/cv/` from the browser produces a clean PDF CV — `styles.css` has a print
stylesheet.
